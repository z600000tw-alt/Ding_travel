# 旅行手帳套件 v2（可套用任何行程）

這個套件可以做出跟「東京手帳」一模一樣的網站：日系繪本風、App 式分頁、多人同步、離線可用。日期、天數、目的地、貨幣和翻譯語言都能直接在網頁上改，所以同一份模板可以一直用在之後的旅行。

## 最快的用法：不用改程式

1. 打開「旅行手帳模板」Claude 網頁，或把 `out/template/site/` 上傳到 GitHub Pages。
2. 到「工具 → 旅行設定」設定：
   - 出發日期、總共幾天；
   - 出發和回家時間（首頁倒數用）；
   - 目的地：搜尋城市後，天氣預報和當地時區會自動跟著改；
   - 當地貨幣、翻譯語言。
3. 在「行程」頁按「編輯」：
   - 改每天的標題、住宿、上方插圖、天氣地點；
   - 新增、刪除、排序行程。
4. 下面這些頁面都有編輯按鈕，直接在網頁上改：
   - 首頁標題（含網站名稱）、航班、緊急聯絡、合照；
   - 住宿、伴手禮、訂位、費用、旅伴與匯率、清單。

## 想一開始就放好資料：改資料檔再建置

```
cp -r trips/template trips/osaka2027      # 複製一份
# 修改 trips/osaka2027 裡的 trip.js、days.json、config.json（說明在下面）
python3 build.py trips/osaka2027
```

輸出到 `out/osaka2027/`：

| 檔案 | 用途 |
|---|---|
| `site/` | 整個資料夾上傳到 GitHub Pages。`index.html` 和 `code.html` 都是旅行密碼版，`google.html` 是 Google 登入版，另外還有離線快取 `sw.js`、manifest、圖示。 |
| `claude.html` | Claude 分享網頁版（Artifact），權限要開 `db` 和 `user`（scopes: profile）。 |
| `local.html` | 單機版，不同步。 |
| `firestore.rules` | Firestore 安全規則。 |

建置時會順便把最新的 `src/main.js` 放回 `src/template.html`。

## 資料夾內容

| 路徑 | 用途 |
|---|---|
| `src/main.js` | 主程式，裡面沒有任何一趟旅行的資料。建置時會把 `trip.js` 放進 `/*__TRIP__*/` 的位置。 |
| `src/template.html` | 版型、CSS、手繪 SVG 插圖和 25 隻動物頭像。 |
| `src/fb_shim.js` | Firebase 同步層，負責：<br>• 登入畫面（旅行密碼＋暱稱，或選用 Google 連結）<br>• 旅伴名單、管理員功能<br>• 備份還原、離線偵測 |
| `src/animals.py` | 產生動物頭像 SVG。 |
| `trips/template/` | 空白模板，預設 5 天、目的地東京，全部可以在網頁上改。 |
| `trips/tokyo/` | 2026 東京 11/14–11/21 的完整資料，也是範例。 |
| `pwa/` | 離線快取 `sw.js`（`__V__` 建置時換成 `cache_name`）、主畫面圖示、`icon-source.html`。 |
| `firebase/firestore.rules` | 安全規則。 |
| `build.py` | 建置腳本。 |

## trips/<名稱>/ 裡的檔案

### config.json

| 欄位 | 說明 |
|---|---|
| `site_name` | 頁首、主畫面圖示的名稱（網頁上也能改）。 |
| `html_title`、`description` | 網頁標題和說明。 |
| `storage_prefix` | 手機裡存登入資料用的前綴，**每趟旅行都要不一樣**，例如 `osaka27_`。<br>同一個 GitHub 帳號的網站共用同一個網域，前綴一樣的話，登入資料會互相蓋掉。 |
| `cache_name` | 離線快取名稱，**每趟旅行都要不一樣**，例如 `osaka27-v1`。<br>改版時把最後的數字加 1，舊快取就會清掉；不會動到其他手帳的快取。 |
| `keep_photo` | `true` 時保留 `template.html` 裡內建的合照。<br>`false` 時首頁會顯示「放一張大家的合照」，可以在網頁上上傳。 |
| `photo_caption` | 合照下的文字，可以用 `<br>` 換行；填 `null` 表示不改。 |
| `passcode` | 旅行密碼。不同的密碼就是不同的一份資料，所以多趟旅行可以共用同一個 Firebase 專案。 |
| `admin_password` | 預設管理員密碼（進去後可以改）。 |
| `firebase` | Firebase 專案設定（firebaseConfig）。 |

### trip.js（預設資料；第一次打開時的內容，之後的修改存在資料庫）

**基本設定**

| 變數 | 內容 |
|---|---|
| `KEY` | 本機儲存名稱，每趟旅行換一個。 |
| `TRIP` | 欄位見下方。 |
| `DAYINFO` | 每天一筆：`{title, stay, art, loc}`。<br>• `stay`：`HOTELS` 的 key。<br>• `loc`：`[名稱, 緯度, 經度]`。<br>沒寫的天數會自動產生「第 N 天」，插圖自動輪替。 |

`TRIP` 的欄位：

- `start`：第 1 天，`YYYY-MM-DD`。
- `n`：天數，1–30。
- `dep`、`ret`：出發和回家時間，ISO 格式，含時區，例如 `2027-04-03T09:00:00+08:00`。
- `tz`：目的地時區，例如 `Asia/Tokyo`。
- `cur`：貨幣代碼，可用 JPY、KRW、USD、EUR、GBP、THB、VND、HKD、CNY、SGD、MYR、AUD、PHP。
- `lang`：翻譯語言，可用 ja、ko、en、th、vi、fr、de、es、it。
- `loc`：預設天氣地點 `[名稱, 緯度, 經度]`。
- `ph`（可省略）：自訂翻譯常用句 `[[中文, 外文], …]`。
- `scene`（可省略）：首頁插畫，可用 japan（日本・富士山）、korea（韓國・宮殿）、city（城市・高樓）、beach（海島・沙灘）、europe（歐洲・鐘塔）、mountain（山林・湖泊）、asia（南洋・寺廟）。
  - 不寫的話，會依目的地國家自動選（`cc` 是國家代碼，例如 KR），都沒有就用 japan。
  - 網頁上的「旅行設定 → 首頁插畫」也能改。登入畫面的小插圖會跟著換。

`DAYINFO` 的 `art` 插圖可以選（不寫的話，會依首頁插畫的風格自動輪替：第 1 天出發、最後一天回家）：

| key | 插圖 |
|---|---|
| `city` | 城市・晴空塔 |
| `port` | 港口・摩天輪 |
| `tram` | 海邊・電車 |
| `fuji` | 富士山・鳥居 |
| `lake` | 湖畔・楓葉 |
| `shrine` | 神社・鐵塔 |
| `skyline` | 城市・高樓 |
| `beach` | 海邊・椰子 |
| `palace` | 宮殿・古蹟 |
| `europe` | 歐洲・鐘塔 |
| `mountain` | 山林・露營 |
| `stupa` | 寺廟・南洋 |
| `fly` | 出發・飛機 |
| `park` | 樂園・城堡 |
| `shop` | 逛街・購物 |
| `bus` | 移動・巴士 |
| `hotel` | 住宿・放鬆 |
| `home` | 回家・飛機 |

**首頁與航班**

- `HERO`：`{brand, tag, title, route, len}`。`title` 和 `len` 留空時，會自動顯示日期範圍和「N 晚 N+1 天」。
- `FLIGHTS`：去回程航班。

**住宿**

- `HOTELS`、`HOTEL_ORDER`、`HCOL`：住宿資料、順序和卡片顏色。

**伴手禮**

- `CATS`：伴手禮分類。
- `SV`：伴手禮清單。

**訂位・費用**

- `BWHEN`：行程裡有 `bid` 的項目，這裡寫它的時間。
- `BKDEF`：每個訂位項目預設是已訂還是未訂。
- `EXP`：預設費用。`cur` 寫 `"NT$"` 或 `"¥"`；`"¥"` 代表當地貨幣，顯示時會換成 `TRIP.cur` 的符號。
- `MEMBERS`、`RATE`：分帳成員，以及 1 單位當地貨幣等於幾元台幣。

**其他**

- `TODOG`：行前準備和打包清單。
- `KINDS`：行程類型的名稱。
- `JA`、`JAH`：給司機看的當地語言名稱和地址，分別用行程 id、住宿 key 對應。
- `SOS`：緊急聯絡 `[名稱, 電話, 說明]`。

### days.json

每天一個陣列，陣列裡每一站是：

```
{id, n, t, k, tr, img, stay, bid, info}
```

| 欄位 | 內容 |
|---|---|
| `id` | 唯一的 id。 |
| `n` | 名稱。 |
| `t` | 時間。 |
| `k` | 類型：spot、meal、move、stay。 |
| `tr` | 交通 `[["train","電車・地鐵"]]`。 |
| `img` | 圖片的 key（`imgs.json` 裡）或網址。 |
| `stay` | 住宿 key。 |
| `bid` | 有填才會出現在訂位頁。 |
| `info` | `{note, how, dur, hours, addr, map:[網址], links:[[標題,網址]], jname, jaddr}`。 |

### imgs.json

內建圖片，格式是 key → base64 WEBP，建議寬 600px、品質 62。

### seed/<集合>/<id>.json

選用。第一次啟用時要預先寫入資料庫的資料。

## Firebase 設定（可以跟其他旅行共用同一個專案）

1. 到 console.firebase.google.com 建立專案，用免費的 Spark 方案。
2. 新增「網頁應用程式」，把 firebaseConfig 複製進 `config.json`。
3. 到「Authentication → 登入方式」，啟用「匿名」和「Google」。
4. 到「Authentication → 設定 → 授權網域」，加上 `帳號.github.io`。
5. 到「Firestore Database」建立資料庫，選 asia-east1、正式版。
6. 在「規則」分頁貼上 `firestore.rules` 並發布。

## GitHub Pages

1. 建立儲存庫，例如 `2027OSAKA`。
2. 上傳 `out/<名稱>/site/` 裡的全部檔案，放在最外層。
3. 到 Settings → Pages，選 Deploy from a branch → main / (root) → Save。
4. 網址是 `https://帳號.github.io/儲存庫名稱/`。

## 功能清單（以後要做一樣的網站時可以對照）

**畫風**

- 日系繪本風：
  - 底色 #FFFCF6，墨灰 #3E3A39 粗線，大圓角，平塗；
  - 配色：珊瑚 #F2A497、山吹 #F6D27A、水色 #A8D3E6、若竹 #B9DAA5；
  - 字型 Huninn。
- 手繪 SVG 插圖會輕輕動，並尊重手機的「減少動態效果」設定。

**App 式分頁**

- 底部 6 個分頁：首頁、行程、住宿、伴手禮、訂位・費用、清單。
- 每個分頁各自記住捲動位置。

**首頁**

- 插畫、可編輯的標題和網站名稱、出發倒數。
- 航班卡（旅行結束後自動收合）。
- 緊急聯絡：一條 SOS 列，一鍵撥號。
- 旅伴名單（可收合）、加到主畫面提示、可換照片的合照、帳號列。

**旅行設定（工具箱）**

- 出發日期、天數、出發和回家時間。
- 目的地搜尋：同時查 Open-Meteo 城市資料和 OpenStreetMap（景點、車站、小鎮都找得到），也可以貼 Google 地圖連結或座標；時區自動帶入；可以一次套用到每一天。
- 當地貨幣、翻譯語言。
- 首頁插畫：7 種風格，可以自動依目的地選；每天上方的插圖也會跟著換風格。
- 天數變少時，多出來那幾天的行程會先藏起來，天數改回來就會出現。

**行程**

- 日期分頁：彈跳切換，分頁上有天氣小圖示。
- 每天的插圖、標題、住宿、天氣地點都能在「編輯」裡改。
- 天氣預報：Open-Meteo，出發前 16 天內才有，依目的地時區。
- 時間軸、交通標籤。
- 新增、刪除、排序、還原這天的原始行程。
- 每站詳細頁：
  - 照片（封面＋「其他照片」，點開全螢幕、左右滑、點兩下放大）；
  - 筆記、地址、地圖、連結；
  - 「給司機看」大字當地語言地址；
  - 討論串。

**住宿、伴手禮**

- 住宿資料。
- 伴手禮：分類篩選、2 欄卡片，可以新增時直接放照片；每個人的「已買」是分開的。

**訂位・費用**

- 訂位：大家共用的已訂／未訂，標籤寫「未訂 N」。
- 費用：
  - 當地貨幣或台幣；
  - 自訂金額或比例分攤，可以多人付款。
- 分帳結算：
  - 最少轉帳次數，可以複製結算貼到 LINE；
  - 「記為已付」、部分付款；
  - 標籤寫「待付 N」，明細可收合。

**清單**

- 行前準備、打包，每個人的勾選是分開的。

**工具箱**

- 即時翻譯：
  - 中文 ⇄ 設定的語言；
  - 語音輸入、念出來、大字給對方看；
  - 離線常用句（日文、韓文、英文內建）。
- 即時匯率：
  - 當地貨幣 ⇄ 台幣；
  - 自動抓匯率，可加稅；
  - 快速金額；
  - 「記一筆費用」、套用為分帳匯率。
- 緊急聯絡。
- 旅行設定。

**留言和通知**

- 每個項目都有討論串，可以編輯、刪除自己的留言；管理員可以刪任何留言。
- 鈴鐺：
  - 「留言」和「最近變更」分開兩個分頁；
  - 每個分頁都有「全部已讀」和「清除已讀」，每個人分開。
- 最近變更：
  - 誰改了什麼，點一下就跳過去；
  - 5 秒內的小動作合併；
  - 同一個人 10 分鐘內改同一項只留一筆；
  - 最多 100 筆，有即時提示。

**同步與帳號**

- Firebase；旅行密碼＋暱稱（匿名登入），或選用 Google 連結。
- 25 隻動物頭像，預設海豹，暱稱範例「海豹」。
- 名字和頭像跨裝置保留，同一台手機不會重複出現。

**我的旅行**（GitHub 密碼版）

- 同一個網站可以放很多趟旅行，每趟用自己的旅行密碼，資料完全分開。
- 帳號列有「我的旅行」，裡面可以：
  - 看到這支手機去過的旅行，一鍵切換；
  - 「新增下一趟旅行」：設新密碼和管理員密碼，從空白模板開始；
  - 「加入其他旅行」：輸入別人給的旅行密碼。

**管理員**（需要管理員密碼）

- 換旅行密碼並搬移資料，舊密碼立刻失效。
- 整理成員、看誰連了 Gmail。
- 改管理員密碼、刪留言。
- 下載備份、從備份還原。

**版本**

- 每次建置會自動產生版本號（建置時間）。
- 只有管理員看得到版本：進入管理員模式後，帳號列會顯示自己的版本，旅伴名單上還在用舊版的人會標「舊版」，管理員名單會列出每個人的版本。
- 一般旅伴看不到版本，但打開舊版時，畫面上方會出現「有新版本・點我更新」。

**離線與主畫面**

- 離線：
  - Service Worker 快取網頁；Firestore 也會把資料存在手機裡；
  - 頁首「離線中」標籤會真的試連網路，不只看有沒有 Wi-Fi。
- 加到主畫面：manifest、apple-touch-icon，全螢幕開啟。
